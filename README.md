# qa_context_study


Online questionnaire for a COS 597B class research project that examines how people use
background information (context) when answering questions, for comparison with
language models.

**Take the questionnaire:** https://<your-username>.github.io/qa_context_study/

Some questions include a short context passage and others do not. Responses are
used solely for this class project and are not shared or used for any other purpose.
